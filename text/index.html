The problem

Given only the headline and the two-sentence lead of a Vietnamese article, predict which of 10 newspaper sections it belongs to: News, World, Business, Sci-Tech, Entertainment, Sports, Law, Education, Health, Travel.

We compare 4 text representations × 4 classifiers, tune the best, test which field carries the signal and whether more data would help, and compare TF-IDF with a pretrained multilingual encoder (multilingual-e5-small) used as a frozen feature extractor.

1. Dataset: how it was collected¶

The group wrote a crawler — text/crawler/crawl_vnexpress.py — using requests + BeautifulSoup:

  1. For each of 10 sections (thoi-su, the-gioi, kinh-doanh, khoa-hoc-cong-nghe, giai-tri, the-thao, phap-luat, giao-duc, suc-khoe, du-lich), visit the listing pages https://vnexpress.net/<section>-p<k> for k = 1…12.
  2. From every article.item-news element extract the headline, the lead paragraph (the location-stamp span such as "Hà Nội" or "Indonesia" is stored separately) and the article URL.
  3. Wait ~1 second between requests; store only headline + lead + URL (no full article bodies) for non-commercial coursework use.

The crawl ran on 27 Sep 2026 (120 requests, ~2.5 minutes). The raw output is kept unmodified in data/vnexpress_news.csv; all cleaning happens in this notebook.

3. Text preparation¶

3.1 Cleaning (VietnameseTextCleaner class)¶

  1. Unicode NFC normalisation — Vietnamese diacritics can be stored as one pre-composed code point (ộ) or as a base letter + combining marks (ô + ̣). Without normalisation the same word would become two different tokens.
  2. Lower-casing.
  3. Replace numbers (1-0, 100.000, 2026) with the token num — exact values rarely indicate the topic.
  4. Remove punctuation and collapse whitespace.
In [5]:
class VietnameseTextCleaner(BaseEstimator, TransformerMixin):
    """Normalise Vietnamese text: NFC, lower-case, numbers -> 'num', strip punctuation."""

    NUM_RE = re.compile(r"\d+(?:[.,:/-]\d+)*")
    PUNCT_RE = re.compile(r"[^\w\s]|_")
    SPACE_RE = re.compile(r"\s+")

    def __init__(self, lowercase=True, replace_numbers=True):
        self.lowercase = lowercase
        self.replace_numbers = replace_numbers

    def clean(self, text):
        text = unicodedata.normalize("NFC", str(text))
        if self.lowercase:
            text = text.lower()
        if self.replace_numbers:
            text = self.NUM_RE.sub(" num ", text)
        text = self.PUNCT_RE.sub(" ", text)
        return self.SPACE_RE.sub(" ", text).strip()

    def fit(self, X, y=None):
        return self

    def transform(self, X):
        return [self.clean(t) for t in X]

3.4 Vectorisation ("encoding" and "scaling" for text)¶

Text must become numbers. We compare four representations, all fit on the training set only:

Representation Idea "Scaling"
BoW counts, 1-gram how many times each syllable occurs none (raw counts)
TF-IDF 1-gram counts re-weighted by rarity across documents sublinear tf + L2 row normalisation
TF-IDF 1–2-gram adds syllable pairs → captures Vietnamese compound words (bóng đá, chứng khoán) sublinear tf + L2
TF-IDF char 2–5 character n-grams inside word boundaries → robust to spelling variants sublinear tf + L2

The token pattern \b\w+\b keeps one-character syllables. scikit-learn's default (\w\w+) would silently drop Vietnamese words such as ô (in ô tô, car) and ở (at/in).

In [8]:

4. What distinguishes the topics?¶

4.1 Most discriminative n-grams per section¶

Question: which words does each section "own"? For each class we run a χ² test of every TF-IDF 1–2-gram against "this section vs the rest" (training set only) and keep the terms that are over-represented in the class.

In [9]:
tfidf12 = VECTORIZERS["TF-IDF 1–2-gram"]().fit(X_train)
Xtr12 = tfidf12.transform(X_train)
terms = np.array(tfidf12.get_feature_names_out())
top_terms = {}
for k, cls in enumerate(CLASSES):
    is_k = (y_train == k).astype(int)
    scores, _ = chi2(Xtr12, is_k)
    in_mean = np.asarray(Xtr12[is_k == 1].mean(axis=0)).ravel()
    out_mean = np.asarray(Xtr12[is_k == 0].mean(axis=0)).ravel()
    scores = np.where(in_mean > out_mean, scores, 0)
    best = np.argsort(scores)[::-1][:8]
    top_terms[cls] = list(zip(terms[best], scores[best]))

Finding (figure 4.1). Two kinds of signal appear:

  • Stable topic vocabulary — Health: bệnh (disease), bác sĩ (doctor), viêm (inflammation), ung (as in ung thư, cancer); Education: học, đại học, học sinh, sinh viên; Law: bị cáo (defendant), cáo buộc, sát hại, tù; Business: cổ phiếu (stock), lãi suất (interest rate), chứng khoán; Travel: du khách, điểm đến.   • Time-specific names — Sci-Tech is driven by iphone, apple, robot; World by trump, iran, ukraine, houthi; Sports by asiad, fifa, cup; and News by recent floods (ngập, mưa lớn, sạt lở). These words reflect the news cycle at crawl time (September 2026), not the section itself — a warning that a model trained on one month may degrade on another (see limitations).

5. Modelling¶

5.1 Feature × model grid (TextBenchmark class)¶

Every combination of 4 representations × 4 classifiers is trained on the training set and scored on validation with macro-F1 (the mean of per-class F1; every section counts equally).

In [11]:
class TextBenchmark:
    """Train every (vectoriser, classifier) pair and record validation scores."""

    def __init__(self, vectorizers, classifiers):
        self.vectorizers = vectorizers
        self.classifiers = classifiers
        self.results = []
        self.pipelines = {}

    def run(self, X_tr, y_tr, X_ev, y_ev):
        for vname, make_vec in self.vectorizers.items():
            for cname, make_clf in self.classifiers.items():
                pipe = Pipeline([("vec", make_vec()), ("clf", make_clf())])
                t0 = time.perf_counter()
                pipe.fit(X_tr, y_tr)
                fit_s = time.perf_counter() - t0
                pred = pipe.predict(X_ev)
                self.pipelines[(vname, cname)] = pipe
                self.results.append({"features": vname, "model": cname, "accuracy": accuracy_score(y_ev, pred),
                                     "macro_f1": f1_score(y_ev, pred, average="macro"), "fit_seconds": fit_s})
        return self

    def table(self):
        return pd.DataFrame(self.results).sort_values("macro_f1", ascending=False).reset_index(drop=True)

    def grid(self, metric="macro_f1"):
        return pd.DataFrame(self.results).pivot(index="features", columns="model", values=metric)

6.3 TF-IDF vs multilingual sentence embeddings¶

Question: does a pretrained neural model that "understands" meaning beat a bag of syllables on short Vietnamese news?

We encode each article with intfloat/multilingual-e5-small (a 118M-parameter multilingual sentence encoder, 384-dim output, trained on ~100 languages including Vietnamese), used as a frozen feature extractor — the model is treated as a ready-made function, as the assignment allows. A Logistic Regression is trained on the embeddings. We also try a hybrid: TF-IDF features concatenated with the embeddings.

This cell needs internet access to download the model (~470 MB) the first time. If sentence-transformers is unavailable, the cell skips gracefully so Run all still completes.

  1. A self-crawled Vietnamese dataset is enough for a strong classifier. 3,769 clean articles across 10 sections give 0.89 macro-F1 from only a headline and a two-sentence lead.
  2. Respecting Vietnamese matters in the details: NFC normalisation, keeping one-character syllables (ô, ở), and syllable bigrams to recover compound words. TF-IDF 1–2-grams beat raw unigram counts by +0.044 macro-F1 for both linear models.
  3. Sentence embeddings beat TF-IDF, and combining them is best. A frozen multilingual encoder adds +0.008 test macro-F1 over tuned TF-IDF; concatenating the two adds +0.027.
  4. The lead paragraph carries more signal than the headline (0.844 vs 0.790 validation macro-F1), and the learning curve flattens after ~1,300 articles.
  5. Errors are predictable: the most confused pair (Business → Sci-Tech) is the most similar pair of section centroids.

Limitations.

  • All articles come from one short window (the latest 12 listing pages per section on 27 Sep 2026); many discriminative words are event names (Trump, ASIAD, iPhone, floods), so accuracy will likely drop on news from another period.
  • One newspaper, one editorial style; labels are the editors' section choices, which are sometimes ambiguous.
  • Syllable n-grams approximate words; a proper Vietnamese word segmenter (e.g. underthesea, pyvi) was not used, to keep the notebook dependency-free.

Future work. Re-crawl in a later month and measure the drop (temporal robustness); crawl other newspapers (Tuổi Trẻ, Thanh Niên) to test cross-source generalisation; compare word-segmented TF-IDF; fine-tune a Vietnamese language model (PhoBERT) lightly on top of the frozen-encoder baseline.
